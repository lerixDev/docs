## الرابط الأساسي (Base URL)

تُرسَل جميع طلبات الـ API إلى نقطة نهاية مشروعك:

```
https://api.atelerix.dev/v1/:project-id
```

استبدل `:project-id` بمعرّف مشروعك من [لوحة تحكم Atelerix](https://app.atelerix.com) ضمن **إعدادات المشروع (Project Settings)**.

**مثال:**

```
https://api.atelerix.dev/v1/my-project-id
```

## المصادقة (Authentication)

قبل استدعاء الـ API، أنشئ **مفتاحاً خاصاً (private key)** من **إعدادات المشروع** في [لوحة التحكم](https://app.atelerix.com).

أرسل المفتاح الخاص في كل طلب ضمن ترويسة (header) باسم `atelerix-api-key`:

```bash
curl https://api.atelerix.dev/v1/my-project-id/endpoint \
  -H "atelerix-api-key: <your-private-key>"
```

<Warning>
  حافظ على سرّية مفتاحك الخاص. لا تضِفه إلى نظام التحكّم بالإصدارات، ولا تعرضه في كود جهة العميل (client-side)، ولا تشاركه علناً.
</Warning>
