## What Lerix does

<CardGroup cols={2}>
  <Card title="Error tracking" icon="bug" href="/modules/error-tracking">
    Crashes and errors grouped by fingerprint, ranked by users affected, with device, OS, version and breadcrumbs. An AI assistant reads the stack trace against your GitHub repo and explains the cause.
  </Card>
  <Card title="Push notifications" icon="bell" href="/modules/push-notifications">
    APNs, FCM and Web Push from one screen. Topics, scheduling, images, custom sounds, per-device delivery status, and update or unsend after delivery.
  </Card>
  <Card title="AI agents (MCP)" icon="robot" href="/developers/mcp">
    A native MCP server so any agent that speaks MCP can create projects, generate push credentials and manage topics for you.
  </Card>
  <Card title="REST API" icon="code" href="/api-reference/introduction">
    Send, update, unsend and cancel notifications, and read deliveries, from your own backend.
  </Card>
</CardGroup>
